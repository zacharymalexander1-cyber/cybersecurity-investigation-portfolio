Cybersecurity Investigation Portfolio

About This Portfolio

This repository is a collection of five Security Operations Center (SOC) investigation case studies covering phishing, authentication attacks, endpoint security, network traffic analysis, and SIEM alert investigation.

The portfolio is designed to demonstrate the investigative workflows, technical knowledge, and documentation practices used by cybersecurity analysts.

Each case follows a structured incident investigation process, including alert triage, evidence examination, event correlation, incident classification, and response recommendations.

Investigation Methodology

Each case is organized around the following workflow:
Initial alert review and investigation scoping
Examination of relevant security evidence
Log analysis and event correlation
Identification of suspicious indicators
Incident classification and severity assessment
Containment and escalation recommendations
Professional incident report documentation
